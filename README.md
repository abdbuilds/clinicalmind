# ClinicalMind

A HIPAA-ready clinical AI agent that answers medical questions grounded in structured
patient data (FHIR) and clinical documents. Built on AWS Bedrock, deployed via AWS CDK.

> Learning project following `CLINICALMIND_MASTER.md`. Uses only synthetic patient data
> (generated by Synthea) — no real PHI.

## Status

🚧 Month 1 · Week 1 · Day 1 — project scaffold.

## Tech stack

- **AWS Bedrock** — foundation models, Knowledge Bases (RAG), Agents, Guardrails
- **AWS Lambda** — agent tools (patient summary, drug interactions, analytics)
- **AWS CDK** — infrastructure as code
- **AWS Glue + Athena** — FHIR → Parquet ETL and clinical analytics (Month 3)
- **Synthea** — synthetic FHIR R4 patient generator

## Repository layout

| Folder | Purpose |
|--------|---------|
| `scripts/` | Standalone Bedrock/KB scripts (Python & TypeScript) |
| `data/` | Synthea generation, sample FHIR files, clinical guidelines |
| `infra/` | AWS CDK stacks |
| `agent/` | Bedrock Agent definition and Lambda tools |
| `knowledge-base/` | Knowledge Base setup and sync scripts |
| `guardrails/` | Guardrail configuration (PHI masking, topic filters) |
| `etl/` | Glue ETL job and Athena queries (Month 3) |
| `demo/` | Screenshots and write-ups |
